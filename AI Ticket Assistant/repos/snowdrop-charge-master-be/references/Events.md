# Charge Master Events## Stream FormatsThis service writes to two event streams.**Company stream** — charge master catalogue events for a company:```Snowdrop.ChargeMasters->{OrganizationId}->Snowdrop.ChargeMasters.Company->{CompanyId}```**ChargeMaster stream** — fee data events for a specific charge master:```Snowdrop.ChargeMasters->{OrganizationId}->Snowdrop.ChargeMasters.ChargeMaster->{CompanyId}_{ChargeMasterId}```Consumers receive events via CosmosDB Change Feed, filtered by entity type name and event class name.  Namespace: `Snowdrop.ChargeMasters.Events`---## Model Types### `CompanyChargeMaster` _(record)_Implements `IOrderableItem`. Represents a charge master entry on a company's catalogue.| Property | Type | Description ||---|---|---|| `ChargeMasterId` | `Guid` | Unique identifier of the charge master. || `Name` | `string?` | Display name (max 120 characters). || `EffectiveStartDate` | `Date` | Start of the effective date range (calendar date, no time component). || `EffectiveEndDate` | `Date?` | End of the effective date range; `null` = open-ended. || `IsDeleted` | `bool` | Soft-delete flag. || `TimeStamp` | `DateTimeOffset` | Last-write timestamp; defaults to `UtcNow`. |---### `FeeIdentity` _(value type, serialised as string)_Implements `IFeeIdentity`. Identifies a fee line within a charge master. Serialised to/from a single string value using `FeeIdentityJsonConverter`.| Property | Type | Description ||---|---|---|| `ChargeCode` | `string` | Procedure / charge code (e.g., CPT code). || `Modifier` | `Guid?` | Optional modifier identifier. || `NDC` | `string?` | Optional National Drug Code. |---### `Fee` _(record)_Implements `IOrderedCollectionItem`. Represents a single fee line within a charge master.| Property | Type | Description ||---|---|---|| `FeeIdentifier` | `FeeIdentity` | Identifies the fee — see [FeeIdentity](#feeidentity-value-type-serialised-as-string). || `Amount` | `decimal` | Fee amount. || `IsDeleted` | `bool` | Soft-delete flag. || `TimeStamp` | `DateTimeOffset` | Last-write timestamp; defaults to `UtcNow`. |---## Base Class Serialisation Pattern### `OrderableItemUpdatedEventBase<TKey, TItem>`Used by `CompanyChargeMasterAdded`, `CompanyChargeMasterUpdated`, and `CompanyChargeMasterDeleted`.
