Schedule Fees ID is `{GlobalFeeScheduleId}_{AllowedScheduleId}` (not lower-cased).---## Base Classes### `PayerEvent` (`Events/Payers/PayerEvent.cs`)Abstract base for all payer-scoped events. Provides `PayerId` (`Guid`).### `PlanEvent` (`Events/Plans/PlanEvent.cs`)Abstract base for all plan-scoped events. Provides `PlanId` (`Guid`).### `ContractEvent` (`Events/Contracts/ContractEvent.cs`)Abstract base for contract association events. Provides `ContractId` (`Guid`). Note: the primary contract CRUD events (`PayerContractAdded`, `PayerContractUpdated`, `PayerContractDeleted`) do NOT extend `ContractEvent`; they extend `OrderedCollectionItemUpdatedEventBase` and carry `PayerId` instead.### `ManufacturerCopayProgramEvent` (`Events/ManufacturerCopayProgram/ManufacturerCopayProgramEvent.cs`)Abstract base for manufacturer copay program events. Provides `ManufacturerCopayProgramId` (`Guid`). Note: a few MCP events (`ManufacturerCopayProgramDeleted`, `ManufacturerCopayProgramLegalNameUpdated`, `ManufacturerCopayProgramAddressUpdated`) do NOT extend this base and declare `ManufacturerCopayProgramId` directly.### `SnfEvent` (`Events/Snf/SnfEvent.cs`)Abstract base for SNF events. Provides `SnfId` (`Guid`).### `SnfPatientEvent` (`Events/Snf/Patient/SnfPatientEvent.cs`)Abstract base for SNF patient events. Provides `SnfPatientId` (`Guid`) and `PatientId` (`Guid`).### `OrderedCollectionItemUpdatedEventBase<TKey, TItem>` (from `Snowdrop.Core`)Base for all events that add, update, or soft-delete an item in an ordered collection. The item is stored as a named JSON object (the `[JsonProperty("CollectionPropertyName")]` attribute on `Collection`). The item is accessible via the `Item` property inherited from the base. When an event marks an item deleted, it sets `item.IsDeleted = true` in the constructor.### `OrderedCollectionOrderUpdatedEventBase<TKey>` (from `Snowdrop.Core`)Base for events that re-order an existing collection. The new order is stored as a named JSON object (the `[JsonProperty("CollectionPropertyName")]` attribute on `OrderJsonProperty`).---## Model Types### Enums#### `PayerStatus``Active = 0`, `Inactive = 1`#### `PayerType`| Value | Display name | Notes ||-------|-------------|-------|| `Insurance = 0` | Insurance | || `SelfPay = 1` | SelfPay | || `SkilledNursingFacility = 2` | Snf | || `Manufacturer = 3` | ManufacturerCopayer | **Obsolete** — use `ManufacturerAssistance` || `ManufacturerAssistance = 4` | Manufacturer | Assistance payer || `FoundationAssistance = 5` | Foundation | Assistance payer || `OtherAssistance = 6` | Other | Assistance payer |#### `PlanStatusType``Active = 0`, `Inactive = 1`#### `FeeScheduleType``FromUpload = 0`, `FromChargemaster = 1`, `FromGlobal = 2`#### `SnfStatusType``Inactive = 0`, `Active = 1`#### `ManufacturerCopayProgramStatusType``Inactive = 0`, `Active = 1`#### `ManufacturerDataSource``AssistPoint = 0`, `TailorMed = 1`#### `ContactPointType` (Payers and Plans namespaces — identical)`Phone = 0`, `Email = 1`, `Fax = 2`#### `PreferredVerificationMethod``Unassigned = 0`, `RTE = 1`, `Phone = 2`, `Website = 3`#### `VerificationInterval``Unassigned = 0`, `Daily = 1`, `Weekly = 2`, `Monthly = 3`, `Yearly = 4`#### `Payer.AutoAdjustmentReasonTypes` (nested enum)`Contractual`, `NonContractual`---### Classes and Records#### `PayerName`| Property | Type | Description ||----------|------|-------------|| `Display` | `string` | Display name of the payer |#### `PayerClassification`| Property | Type | Description ||----------|------|-------------|| `IsInsurancePayer` | `bool` | Whether this payer is an insurance payer |#### `PayerContactPoint`Implements `IOrderedCollectionItem`.
