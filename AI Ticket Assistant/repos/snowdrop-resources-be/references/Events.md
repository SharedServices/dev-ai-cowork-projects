# Resources EventsSource application name: `snowdrop-resources`---## Stream FormatsEach stream is identified as `snowdrop-resources->{OrganizationId}->EntityTypeName->{EntityId}`.| Stream | Format ||--------|--------|| Company | `snowdrop-resources->{OrganizationId}->company->{CompanyId}` || Facility | `snowdrop-resources->{OrganizationId}->facility->{FacilityId}` || Provider | `snowdrop-resources->{OrganizationId}->provider->{ProviderId}` || Payment Device | `snowdrop-resources->{OrganizationId}->payment-device->{DeviceId}` || Payment Vendor | `snowdrop-resources->{OrganizationId}->payment-vendor->{OrganizationId}` || Monthly Close | `snowdrop-resources->{OrganizationId}->monthly-close->{MonthlyCloseId}` || Division Ledger | `snowdrop-resources->{OrganizationId}->division-ledger->{DivisionId}` || Facility Resource | `snowdrop-resources->{OrganizationId}->facility-resource->{FacilityResourceId}` || Human Resource | `snowdrop-resources->{OrganizationId}->human-resource->{HumanResourceId}` |**Notes on stream IDs:**- Division events (all `Divisions\*` event classes) implement `ICompanyEvent` and are published to the **Company** stream, keyed by `CompanyId`.- The **Payment Vendor** stream is unusual: the entity ID equals the organization ID (there is one vendor configuration document per organization).- Ledger events (`ChargeLedgerClosed`, `PaymentLedgerClosed`) do **not** implement `IResourceEvent`. They implement `IChargeLedgerOwner`/`IPaymentLedgerOwner` and are published to the **Division Ledger** stream via `DivisionIdentifier` in `Snowdrop.Resources.Ledger`.---## Base Interfaces### `IResourceEvent` (`Events/IResourceEvent.cs`)Marker interface for all resource events. No properties.### `ICompanyEvent` (`Events/Companies/ICompanyEvent.cs`)Extends `IResourceEvent`. Marker interface for company and division events. No properties.### `IFacilityEvent` (`Events/Facilities/IFacilityEvent.cs`)Extends `IResourceEvent`. Marker interface for facility events. No properties.### `IMonthlyCloseEvent` (`Events/MonthlyClose/IMonthlyCloseEvent.cs`)Extends `IResourceEvent`. Marker interface for monthly close events. No properties.### `IPaymentDeviceEvent` (`Events/Payments/IPaymentDeviceEvent.cs`)Extends `IResourceEvent`. Marker interface for payment device events. No properties.### `IPaymentVendorEvent` (`Events/Payments/IPaymentVendorEvent.cs`)Extends `IResourceEvent`. Marker interface for payment vendor events. No properties.### `IProviderEvent` (`Events/Providers/IProviderEvent.cs`)Extends `IResourceEvent`. Marker interface for provider events. No properties.### `IFacilityResourceEvent` (`Events/SchedulingResources/IFacilityResourceEvent.cs`)Extends `IResourceEvent`. Marker interface for facility scheduling resource events. No properties.### `IHumanResourceEvent` (`Events/SchedulingResources/IHumanResourceEvent.cs`)Extends `IResourceEvent`. Marker interface for human scheduling resource events.
